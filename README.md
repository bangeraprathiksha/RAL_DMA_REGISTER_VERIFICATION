# RAL_DMA_REGISTER_VERIFICATION

This repository contains a UVM-based Register Abstraction Layer (RAL) verification environment for a DMA controller. The environment verifies DMA configuration and control registers using frontdoor and backdoor read/write operations, ensuring correct register functionality. It includes a complete UVM register model, sequences, driver, monitor, coverage, and self-checking mechanisms to validate desired, mirrored, and DUT values. Functional coverage is collected to ensure register field combinations are exercised, and error scenarios are checked for correctness.
